## [1.0.0] - 2026-09-25

### Added
- Shared validation engine for information handling and neural synthesis.
- JOSS editorial bot (`scripts/joss_editorial_bot.py`) with TRL readiness scoring
  (research norm 85-100/100) and live readiness matrix.
- `joss-editorial.yml` workflow (check / submit modes, dry-run support).
- Full paper metadata: `CITATION.cff`, `paper/paper.md` (2026 JOSS format),
  `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `LICENSE`.
- Bio-inspired adaptive cyber-immunity security policy (`SECURITY.md`).
- Dependabot configuration (pip + GitHub Actions).
- CI pipeline: unit tests, packaging checks, builds.
- Security Audit workflow (gitleaks, CycloneDX SBOM, pip-audit, license scan,
  dependency-pinning assertion).

### Changed
- Register `_ADAPTERS` after context definitions so modules import cleanly.
